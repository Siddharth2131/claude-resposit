# Let's Talk briefing: Consent Before Code

| File | Purpose |
|---|---|
| `Consent_Before_Code_Briefing.pptx` | Slide deck (9 slides, speaker notes on each) |
| `Presenter_Guide.docx` / `.md` | Timed script, chart method, Q&A preparation, verification log, references |
| `make_chart.py` | Python script that builds the chart from `language_data.csv` |
| `language_data.csv` | Published ABS 2021 Census figures, with source column |
| `figure_language_concentration.png` | Chart output (300 dpi) |
| `build_deck.js` | Rebuilds the deck (`npm install pptxgenjs`, then `node build_deck.js`) |

Run the chart: `pip install matplotlib` then `python make_chart.py`.
